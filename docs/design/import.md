# Загрузка справочников из xls/xlsx

Статус: проект для задачи T-033. Решения — D-142–D-146 в `docs/decisions.md`. Модель данных — `docs/design/catalogs.md`.

## Сценарий

1. Руководитель или администратор загружает файл `.xls` или `.xlsx` — `POST /api/v1/imports` (multipart, поле `file`).
2. API проверяет файл, читает первый лист, определяет строку заголовков и предлагает сопоставление столбцов с полями CRM по синонимам заголовков. Ответ: идентификатор загрузки, заголовки, предложенное сопоставление, число строк, первые 20 строк.
3. Пользователь при необходимости меняет сопоставление и запускает проверку — `POST /api/v1/imports/{id}/check`. Ничего не записывается; по каждой строке возвращается результат: что будет создано или обновлено, ошибки и предупреждения.
4. Пользователь применяет загрузку — `POST /api/v1/imports/{id}/apply` с тем же сопоставлением. Все корректные строки записываются одной транзакцией; строки с ошибками пропускаются и перечисляются в отчёте. Повторное применение той же загрузки — `409 CONFLICT`.
5. Отчёт доступен по `GET /api/v1/imports/{id}`; в журнал действий пишется одно событие `import.apply` с итогами.

## Правила разбора строк

- **Даты:** ячейки-даты Excel, а также текст `ДД.ММ.ГГГГ` и `ГГГГ-ММ-ДД`. Если срок действия пуст — дата подписания + 1 год.
- **Статус передачи:** код (`in_progress`) или подпись («Идёт передача»); пусто — «Не начата».
- **Вуз** ищется по названию (пробелы нормализуются); если не найден — создаётся, город остаётся пустым, в отчёте предупреждение.
- **ИТ-продукт** ищется по паре «вендор + ПО»; если не найден — создаётся. Направления из столбца `it_directions` (через `;` или `,`) создаются при отсутствии и привязываются к продукту.
- **Договор** ищется по номеру: найден — обновляется, иначе создаётся. Если номер повторяется внутри файла, используется последняя строка, остальные отмечаются предупреждением.
- **Менеджер** сопоставляется с пользователями CRM по ФИО; нет или несколько совпадений — ФИО сохраняется текстом в `manager_name`, предупреждение (D-140).
- **Ответственные от вуза** — список ФИО через `;` или перевод строки; отсутствующие контакты вуза создаются и привязываются к договору.
- **Ошибка строки:** пустое обязательное поле, неразборчивая дата, неизвестный статус, срок действия раньше подписания, превышение длины поля.

## Ограничения и безопасность

- Размер файла — до 10 МБ; строк данных — до 5000; сумма распакованных частей xlsx — до 100 МБ (защита от «zip-бомб»). Тип проверяется по сигнатуре содержимого, а не только по расширению.
- Формулы не вычисляются: берутся сохранённые в файле значения.
- Разобранные строки хранятся в таблице `catalog_imports` вместе с отчётом; исходный файл не сохраняется.
- Загрузку выполняют только руководитель и администратор.
