# Настройки → Резервное копирование — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Статус и даты настоящих копий для суперадминистратора и безопасный ручной запуск через флаг запроса.

**Spec:** `docs/superpowers/specs/2026-09-27-backup-settings-design.md`

## Global Constraints
- Ветка `ai/profile-senders`; миграций нет.
- Только `crm-superadmin`; без путей, ключей и выдачи файлов; без восстановления и удаления.
- Не устанавливать plist и не запускать копии на рабочем Mac; не пушить, не выпускать.

## Review Focus
- Флаг создан, агент упал — запрос не должен висеть вечно: отчёт `running` старше 6 часов считается прерванным.
- Два быстрых нажатия — один запрос (`409` на второе, атомарное создание файла).
- Каталоги отсутствуют (локальная разработка) — «недоступно», не 500.
- Отчёт с неизвестной `schema` — «повреждён».
- Часы: время в отчёте — UTC ISO; показ — по часовому поясу профиля не требуется, достаточно браузера.
