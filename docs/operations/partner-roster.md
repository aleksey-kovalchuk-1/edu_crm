# Начальный список вузов

27 сентября 2026 года заказчик передал десять названий вузов для начального рабочего списка. Это источник утверждения о сотрудничестве с Ростелекомом; открытые сайты вузов используются только для заполнения города. Новые вузы сотрудники смогут добавлять через «Настройки → Учебные заведения», поэтому десять — стартовый состав, а не постоянный предел.

Города сверены со страницами самих вузов: [МФТИ](https://pk.mipt.ru/contacts/), [Московский Политех](https://mospolytech.ru/ob-universitete/adresa-i-kontakty/), [ИТМО](https://itmo.ru/ru/page/329/rekvizity.htm), [СПбПУ](https://www.spbstu.ru/sveden/), [СПбГУТ](https://www.sut.ru/), [ТПУ](https://tpu.ru/university/contacts/), [ЮУрГУ](https://abit.susu.ru/kontakty/), [РГУ им. А.Н. Косыгина](https://rguk.ru/contacts/), [ВолгГТУ](https://www.vstu.ru/sveden/struct/), [ВятГУ](https://new.vyatsu.ru/sveden/common/).

Перед применением выполните `python -m app.sync_partner_universities` в API-контейнере. Команда без `--apply` показывает только числа будущих изменений. Затем после зашифрованной пары резервных копий запустите её с `--apply`. Она не удаляет и не переименовывает шесть демонстрационных вузов: делает их неактивными, сохраняя ссылки из прежних задач и взаимодействий. Если в базе есть другой действующий вуз, команда остановится, чтобы оператор проверил его вручную. Повторный запуск на неизменённом списке не создаёт дублей.
