# Коды ошибок API

Любой ответ API с ошибкой имеет одинаковый формат:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "Проверьте заполненные поля",
  "details": [{"field": "name", "message": "String should have at least 1 character", "type": "string_too_short"}]
}
```

- `code` — постоянный идентификатор ошибки; по нему интерфейс и служба поддержки определяют причину.
- `message` — текст для пользователя на русском языке.
- `details` — уточнения (например, поля формы с ошибками) или `null`.

Внутренние подробности сбоев (трассировки, SQL, сообщения библиотек) в ответ не попадают — они записываются в журнал сервера.

| Код | HTTP | Сообщение по умолчанию | Когда возникает |
|---|---|---|---|
| `BAD_REQUEST` | 400 | Некорректный запрос | Запрос нельзя обработать в текущем виде |
| `UNAUTHENTICATED` | 401 | Требуется вход в систему | Нет действующей сессии |
| `FORBIDDEN` | 403 | Недостаточно прав для этого действия | Роль или область доступа пользователя не позволяет действие |
| `NOT_FOUND` | 404 | Ресурс не найден | Неизвестный адрес API |
| `RECORD_NOT_FOUND` | 404 | Запись не найдена | Запрошенная запись отсутствует |
| `METHOD_NOT_ALLOWED` | 405 | Метод не поддерживается | Адрес существует, но не поддерживает этот HTTP-метод |
| `CONFLICT` | 409 | Конфликт данных: запись изменена или уже существует | Дубликат или одновременное изменение |
| `PAYLOAD_TOO_LARGE` | 413 | Слишком большой объём данных | Превышен допустимый размер файла или запроса |
| `UNSUPPORTED_MEDIA_TYPE` | 415 | Неподдерживаемый формат данных | Недопустимый тип файла или содержимого |
| `VALIDATION_ERROR` | 422 | Проверьте заполненные поля | Данные не прошли проверку; поля перечислены в `details` |
| `RATE_LIMITED` | 429 | Слишком много запросов, повторите позже | Превышен лимит запросов |
| `INTERNAL_ERROR` | 500 | Внутренняя ошибка сервера | Непредвиденный сбой |
| `SERVICE_UNAVAILABLE` | 503 | Сервис временно недоступен | Недоступна база данных или другой обязательный компонент |

Список кодов проверяется автоматически: тест `backend/tests/test_errors.py` падает, если код добавлен в каталог, но не описан здесь.
