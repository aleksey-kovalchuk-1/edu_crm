## Область поставки

Исходный код React и FastAPI поставляется как текст без обфускации. Контейнеры собираются из него. Локальный запуск использует PostgreSQL и Keycloak. По решению владельца LMS и сайт ИТ Школы всегда представлены заглушками: действующего обмена нет и он не запланирован. Схема постоянных заглушек пока описана как проект, не как реализованный коннектор. Юридическое заключение о соответствии 149-ФЗ, 152-ФЗ и ГОСТ не входит в программную документацию: его должен дать профильный юрист/специалист по защите информации по фактическим данным и условиям эксплуатации.

## Приёмочная проверка комплекта

1. Запустить систему по [инструкции](linux-install.md), открыть Swagger UI и проверить ролевой вход.
2. В «Отчётах» выбрать период, вуз и колонки; сопоставить число строк предпросмотра и поля полного JSON. При более чем 200 строках предпросмотр показывает первые 200, а файл содержит все доступные строки.
3. Открыть файл как UTF-8 JSON и проверить `total`, `columns`, `filters` и `rows`. Повторить вход под КАМ с меньшей областью доступа: чужие вузы не должны появиться в файле.
4. Проверить «Аналитику» и PDF по правилам из [обработки данных](data-processing.md); демонстрационный вид в браузере не является подтверждённой статистикой.
5. Импортировать [модель](unicrm-architecture.xml) в Archi и проверить отображение элементов и связей. Синтаксис XML и ссылки между элементами проверены автоматически; графическое размещение в конкретной версии Archi требует ручной проверки.
