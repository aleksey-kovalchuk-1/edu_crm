# Компоненты и библиотеки

Версии в таблице относятся к исходному коду от 28.09.2026. Полный машинный перечень пакетов и точных зависимостей дан в `backend/requirements.txt`, `backend/constraints.txt`, `backend/requirements-dev.txt`, `frontend/package.json` и `frontend/package-lock.json`. При поставке эти файлы передаются вместе с исходным кодом; обновление пакета требует повторной проверки лицензии и совместимости.

| Слой | Компоненты / библиотеки | Назначение |
| --- | --- | --- |
| Язык серверной части | Python 3.12 | прикладная логика |
| HTTP и схема API | FastAPI 0.141.1, Uvicorn 0.52.4, Pydantic через FastAPI | маршруты, проверка запросов, Swagger UI / OpenAPI |
| Хранение | PostgreSQL 16 Alpine, SQLAlchemy 2.0.52, psycopg 3.3.5, Alembic 1.20.0 | реляционные данные и миграции |
| Вход | Keycloak 26.7.3, PyJWT 2.14.0, httpx 0.28.1 | OIDC, роли, взаимодействие с Keycloak |
| Excel | openpyxl 3.1.5, xlrd 2.0.2, xlwt 1.3.0 | чтение и запись XLS/XLSX |
| PDF | ReportLab 5.0.1, DejaVu Sans в `backend/app/fonts/` | кириллические PDF-отчёты |
| Формы | python-multipart 0.0.32, email-validator 2.3.0 | загрузка файлов и валидация адресов |
| Интерфейс | React 19.1.0, React DOM 19.1.0, React Router 7.18.3, TanStack Query 5.102.8 | страницы, маршруты и серверное состояние |
| Компоненты интерфейса | dnd-kit core 6.3.1 / sortable 10.0.0 / utilities 3.2.2, lucide-react 0.468.0 | перетаскивание и иконки |
| Сборка интерфейса | Node.js 22 Alpine, TypeScript 5.8, Vite 6.3.5 | типизация и статическая сборка |
| Веб-сервер | Nginx 1.28 Alpine | статический интерфейс и прокси API / Keycloak |
| Проверки | pytest 9.1.1, pypdf 6.10.0, Vitest 5.0.0, Testing Library, ESLint | серверные и браузерные тесты, проверка PDF и стиль |
| Необязательный BI | Apache Superset, образ из `superset/Dockerfile` | отдельная аналитическая среда при включённом профиле `analytics` |

Python стандартная библиотека обеспечивает JSON, работу с датой, HMAC и файловыми потоками. JSON-экспорт не добавляет внешнюю библиотеку. Список транзитивных библиотек Python зафиксирован в `backend/constraints.txt`; транзитивные JS-пакеты и контрольные суммы — в `frontend/package-lock.json`. Состав контейнеров задаёт `compose.yaml`, а публичные изменения — `compose.public.yaml`.

В проекте также используются шрифты DejaVu Sans; условия их распространения проверяются отдельно при передаче пакета заказчику. Исходники приложения поставляются без обфускации; минификация статического интерфейса при сборке служит доставке в браузер и не заменяет исходный код.
