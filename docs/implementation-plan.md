# CRM учебных заведений — первый рабочий шаблон

Цель: похожие на CRM B2B, IQHR и ЛКО рабочие сценарии: единое окно, связанные карточки, этапы, ответственные и аналитика. Все исходные сведения демонстрационные.

Архитектура: React + TypeScript → /api/v1 → FastAPI → SQLAlchemy → PostgreSQL. Для локальной проверки допускается SQLite. Docker Compose запускает PostgreSQL, API и nginx с собранным интерфейсом. Superset — отдельный опциональный профиль.

1. Создать API-контракт и тесты создания учебного заведения, запуска, изменения этапа и задачи. Проверить отклонение неверного этапа и отсутствующего вуза.
2. Реализовать БД, API, демоданные и историю этапов. Проверить тесты.
3. Реализовать обзор, реестр, доску взаимодействий, задачи, аналитику, формы создания и карточку запуска. Подключить только реальные ответы API.
4. Добавить Docker, README, CI; собрать frontend, проверить API и интерфейс. Зафиксировать стартовый коммит.

Границы: это локальный демонстрационный шаблон без авторизации, реальной LMS, электронной подписи и подтверждения нормативного соответствия. Привязка портов только к loopback. Реальные персональные данные не загружать до реализации доступа.
